# Lesson 1 Golden Scenarios

- `lesson1_worked_example.json`: Records the 4-event worked example from Lesson 1 Section E. It serves as an immutable reference specification for matching engine development.
- `lesson1_hand_simulation.json`: Records the 5-event hand simulation problem from Lesson 1 Section H (including initial book, all 5 events, spread in ticks and dollars, explicit cancel/expire event for the 600 unfilled IOC shares in event 5, and complete `original = filled + cancelled + resting` order accounting). It becomes our first matching-engine acceptance test in Lesson 3.
